{{NAME}} is a local-only diagram and infographic tool. You draw with the mouse, and every diagram is saved as a readable file that diffs cleanly in git. Nothing leaves your machine.

Built around three ideas

Canvas first

Place things where you want them, to the pixel. The file stores the positions, so the diagram looks the same tomorrow as it does today.

Diagram as code

Files are plain text. Review them in a pull request, hand-edit them, or have a script or an LLM generate them.

Local only

{{NAME}} is one small program on your computer. It makes no network requests at runtime, and your diagrams belong to you.

What you can do

An infinite canvas

Pan with the hand tool, space-drag or trackpad. Zoom with a pinch or the keyboard, to fit or to a selection. Turn the grid and snapping on or off.

Screenshot: canvas navigation

Connectors that stay attached

Arrows follow the shapes they join. Route them straight or with elbows, add bend points, label them, and re-attach an end by dragging it.

Screenshot: connectors

A shape library

Start with a core set and add data-only shape packs. Type a label straight into a shape and drop in images by pasting or dragging.

Screenshot: shape library

Style it your way

Fonts, sizes and colours for text. Fill, stroke, dash, corner radius and opacity for shapes. A colour picker remembers your recent colours.

Screenshot: style panel

Projects and files

Keep diagrams in project folders, or open any folder or file from the command line. Autosave, undo and redo, and copy and paste between files are built in.

Screenshot: projects

The file is the diagram

Every save writes the same canonical text, so a one-box change is a one-line diff.

diagram version=1 title="Order flow" {
  plugins core@1 arch@1
}

node api "API Gateway" shape=arch.gateway
node orders "Order Service" shape=arch.server
node db "Orders DB" shape=arch.database

edge api orders label="POST /orders"
edge orders db

layout {
  api    x=40  y=150 w=160 h=60
  orders x=280 y=150 w=180 h=60
  db     x=260 y=320
}

Install

  1. Download

    Get the latest macOS build from the releases page. Linux and Windows builds follow.

  2. Allow it to run

    The binary is not signed yet, so macOS will block the first launch. Clear the quarantine flag once:

    xattr -d com.apple.quarantine ./drawit
chmod +x ./drawit

  3. Run it

    Start it with a folder, or with nothing to open the start screen. Your browser opens on the canvas.

    ./drawit ~/diagrams
